# 리본 아틀리에 · 아바타 탈의실

## 실행

Ribbon-Atelier.html을 추출해서 브라우저에서 열어. 이미지와 동작이 이 파일에 들어 있어서 인터넷 없이 옷장과 일정 관리를 할 수 있어. 영어 손글씨 인식은 모델과 라이브러리 다운로드에 인터넷이 필요해. 캐릭터를 탭하면 잠깐 웃고, 각 탭에서 다른 아이템을 선택할 수 있어.

선택한 코디는 브라우저의 로컬 저장소에 기록돼. 같은 브라우저에서 같은 경로의 HTML을 다시 열면 해당 코디가 복원돼. 파일 미리보기가 저장소 접근을 제한하면 브라우저에서 직접 열어.

## 오늘 할 일과 상점

부모 관리에서 이전 주·다음 주로 이동하거나 오늘로 돌아온다. 월요일부터 일요일 중 날짜를 골라 할 일과 보상 코인을 등록한다. 수정에서 제목, 보상, 날짜를 바꿀 수 있다. 삭제한 일정은 원래 날짜의 삭제한 일정 목록에서 복원한다. 오늘 할 일에서는 기기 날짜에 맞는 일정과 완료 개수를 보여 준다. 완료 보상은 일정당 한 번 지급되며, 완료 취소는 체크 상태만 되돌린다. 민트 데이지 원피스는 상점에서 10코인으로 살 수 있고, 구매 후 옷장에 표시된다.

할 일과 장부는 브라우저 저장소의 ribbon-atelier.economy.v1 키를 사용한다. 활동 ID와 아이템 ID를 거래 키로 써서 중복 지급과 중복 구매를 방지한다. 일정 수정·삭제·복원에도 기존 일정 ID와 지급 기록을 유지한다. 구매 거래에서 소유 여부를 읽고 전체 거래 합계로 잔액을 계산한다. 기존 코디 저장소의 키는 기존과 동일하다.

## 일상복 상하의

갈아입기에서 상의 또는 하의를 고르면 일상복 모드로 전환된다. 상의 3종과 하의 3종이 각각 독립된 슬롯이라 아홉 가지 조합을 만들 수 있다. 한 벌 탭에서 기존 드레스나 기본복을 고르면 상하의가 가려진다. 일상복 여섯 파츠, 심플 밤색 단발, 햇살 벽과 나무 바닥은 기본 제공한다. 심플 밤색 단발은 턱선 길이의 보브컷이다. 토끼 리본 후드티는 상점에서 10코인으로 구입하고 상의에서 선택한다.

## 부모 관리 도구

할 일과 보상 코인을 입력하고 자주 쓰기에 저장한다. 주간 달력에서 날짜를 고른 뒤 자주 쓰는 할 일을 누르면 바로 등록된다. 같은 날에는 같은 일정이 중복되지 않는다. 그날 삭제했던 일정과 같으면 원래 일정 ID와 기존 지급 기록으로 복원한다.

주간 학습 기록은 달력에서 본 주의 할 일 완료율, 영어 시험·복습 정답률, 자주 틀린 단어를 보여 준다.

전체 백업 · 복원에서 일정, 삭제 상태, 자주 쓰는 할 일, 코인 장부, 구매, 현재 착용, 코디 목록, 영어 단어장과 기록을 JSON으로 내보낸다. 복원하면 브라우저의 데이터를 백업 시점으로 교체한다. 같은 파일을 여러 번 가져와도 장부가 합산되지 않는다. 이전 영어 전용 백업은 영어 탭에서 불러온다. 같은 메뉴의 입력 데이터 초기화는 일정, 자주 쓰는 할 일, 영어 단어장과 기록을 비우고 코인 장부, 구매, 저장 코디를 유지한다.

## 내 코디와 도감

갈아입기 화면의 코디 저장을 누르면 내 코디의 이름 입력 칸이 열린다. 내 코디에서 조합 이름을 입력하고 저장한다. 입기 버튼으로 의상, 헤어, 신발, 장식, 표정이 함께 바뀐다. 저장한 조합 목록은 현재 착용 상태와 별도인 ribbon-atelier.looks.v1 키에 저장된다.

도감은 그림이 있는 수집 아이템의 보유 상태를 보여 준다. 미보유 아이템은 상점 보기로 구매 화면을 열 수 있다. 추가 상점 품목은 밤빛 양갈래 15코인, 허니 끈 구두 12코인, 데이지 꽃핀 6코인이다.

## 영어 받아쓰기

영어 탭에는 english-dictation-9.html 원본의 시험·필기·채점 엔진을 연결한다. 원본 파일은 그대로 보관한다. 기존 단어장과 시험 기록은 같은 저장소에 있으면 이어서 열리며, 기존 파일의 기록 탭에서 내보낸 JSON도 가져올 수 있다. 불러온 과거 기록에는 코인을 지급하지 않는다.

시험에서 답안을 제출하면 기본 3코인, 정답률 80% 이상이면 2코인 추가, 처음 보상받는 장이 포함된 시험이면 세션당 최대 2코인을 추가한다. 오답 복습에서 한 문제 이상 맞히면 2코인이다. 영어 보상 전체는 기기 날짜 기준 하루 최대 15코인이고, 세션 ID당 한 번만 처리한다. 전부 건너뛴 시험은 기록으로 남는다. 손글씨 또는 키보드로 답할 수 있다.

## 나의 방

캐릭터 화면의 나의 방이나 옷장의 방 꾸미기를 누르면 배경과 펫을 고를 수 있다. 라일락 방은 기본 제공하고, 햇살 정원은 20코인, 토끼 모찌는 15코인에 상점에서 살 수 있다. 펫을 탭하면 하트로 반응하며 움직임 설정으로 귀나 뛰는 연출을 끌 수 있다. 방과 펫은 현재 코디, 저장한 코디, 전체 백업에 함께 기록한다.

## 소리

오른쪽 위 음표에서 배경음과 효과음의 켜짐 상태와 음량을 따로 조절한다. 배경음은 첫 화면 조작 이후 옷장과 방 꾸미기에서 재생한다. 영어·할 일·부모 관리·상점으로 이동하면 일시 정지한다. 코인 획득, 구매, 코디 변경, 펫 인사에 각각 다른 효과음이 나온다. 설정은 현재 코디 저장 데이터와 전체 백업에 함께 보관한다.

오르골 루프는 assets/music-room.ogg에 포함되어 있다. 새로 렌더링하려면 ffmpeg가 설치된 환경에서 python3 compose_room.py를 실행한다.

## 아이템 추가

1. assets 폴더에 1024 × 1536 RGBA PNG를 추가한다. 크기와 관절 위치는 body.png와 bare-feet.png를 겹친 기준 바디에 맞춘다. 목록용 프리뷰에는 작은 WebP를 사용한다.
2. catalog.json의 items에 고유 id, name, category, slot, preview, layers를 추가한다. 각 레이어에는 id, PNG path, z를 지정한다. z가 클수록 앞으로 렌더링한다.
3. hidesSlots에는 가릴 장착 슬롯을 지정한다. hidesLayers에는 숨길 레이어 ID를 지정한다. masks에는 가릴 레이어 ID와 마스크 경로를 등록한다. 마스크는 알파 255 영역을 유지하고 알파 0 영역을 가린다. 소매 길이에 맞게 몸통과 팔을 가릴 영역을 지정한다. 레이어에 animation 값으로 sway를 지정하면 미세한 흔들림을 추가한다.
4. python3 build.py를 실행해 HTML을 갱신한다. 아이템 ID와 HTML 경로를 유지하면 저장한 코디를 계속 쓸 수 있다. 아이템이 많아지면 python3 build.py --external로 빌드하고 HTML과 assets 폴더를 함께 사용한다.

현재 레이어 순서는 뒷머리 10, 바디 20, 맨발 21, 신발 32, 의상 40, 옷깃 안쪽 목 41, 눈 51, 입 52, 앞머리 65, 머리핀 70이다. 가격이 0이면 시작 지급 아이템으로 옷장에 표시된다. 양의 정수 가격을 가진 아이템은 상점에 표시되며 구매한 뒤 옷장에 나타난다.
